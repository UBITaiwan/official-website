# Flows —— 標準作業流程

這個目錄放的是**專案特有的操作流程**。

AI agent 對一般的網頁開發很在行，但不會知道這個專案的規矩——
哪些設計是刻意的、新增一筆紀錄要加在哪裡、照片能不能直接用。
這些流程就是把那些「它不可能自己知道的事」寫下來。

> **給 AI agent：**有對應 flow 的工作，一律照 flow 做，不要自己發明步驟。
> flow 裡的規則是這個專案特有的，你的通用做法在這裡通常是錯的。

---

## 一定要先看

| 流程 | 什麼時候用 |
|---|---|
| **[修改流程](修改流程.md)** | **每一次改動**。不管改什麼都從這裡開始 |

---

## 特定情況

| 流程 | 什麼時候用 | 狀態 |
|---|---|---|
| 新增一筆紀錄 | 加年度報告、國際交流場次等會進列表頁的內容 | 待補 |
| 換照片 | 替換或新增任何圖片 | 待補 |
| 更新計畫時程 | 生活自由計畫進入下一階段（下次：2026/11/01） | 待補 |
| 出錯回復 | 改壞了要復原 | 待補 |
| 正式上線 | 切換到 ubitaiwan.org | 待 Cloudflare 設定後補 |

---

## 這些流程也會過期

流程描述的是**現在**的做法。網站會改，做法也會改。

發現流程寫的跟實際情況不符時，**以實際情況為準**，並請 AI 更新流程：

> 你做的和 flows 裡寫的不一樣，請確認哪個是對的，然後把流程改成正確的。

已知會讓流程過時的事：

- **Cloudflare 正式環境上線後**——「修改流程」第 6 步提到的 dev 站網址與部署行為會改變
- **部署方式改變時**——同上
