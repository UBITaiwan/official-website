# 校稿

> 檢查網頁上的文字：錯字、通不通順、有沒有照 [寫作規範](../寫作規範.md)、
> 事實有沒有來源。**格式和明顯錯字直接改，需要判斷的才問。**
> 改寫句子、事實對不對，一定要負責人同意才改。

---

## 什麼時候用

| 情境 | 誰啟動 |
|---|---|
| **要推上去之前**，這次有改到網頁上的文字 | **AI 主動做**。[推上去](推上去.md) 的第 1 步就是校稿，負責人不用記得 |
| 改到一半想先確認 | 負責人說「幫我校稿」「幫我看看文字有沒有問題」 |
| 想整頁檢查一遍 | 負責人說「幫我把 XX 頁整頁校稿」 |

只改了版面、圖片、程式，沒有動到文字，就不用校稿。推上去時跟對方說一聲
「這次沒有改到文字，所以不用校稿」，再往下走。

---

## 給 AI 的話

```
幫我校稿。
```

一般的說法也可以，例如「幫我看看文字」「檢查一下有沒有錯字」。

---

## 它應該做什麼

### 1. 確定範圍

**預設只看這個分支改到的文字**，不是整個網站：

```bash
git fetch origin
git diff origin/main -- src/pages src/data
```

這會同時列出已經 commit 和還沒 commit 的改動。只看讀者看得到的文字
（內文、標題、圖片替代文字、頁面描述），程式碼和樣式不看。

**份量跟著改動大小走。**只改了一個錯字，就只看那一句；
新增了整段或整頁，才需要走完下面每一項。

對方說「整頁校稿」時，範圍才是那一整頁。

### 2. 分出原有內容和新內容

| | 怎麼認 | 檢查到什麼程度 |
|---|---|---|
| **原有內容** | `main` 上本來就有的文字（協會已經認可過的聲音） | 只提**錯字、明顯不通順、不符寫作規範**的地方。**不提語氣、措辭偏好、AI 腔** |
| **新內容** | 這個分支新寫、或整段重寫的文字 | 下一步的每一項都要檢查 |

原有內容被這個分支改過時，也要看**改得是不是太多**：
寫作規範說原有內容以微調為主。改動明顯超過微調的話，要問對方。

### 3. 逐項檢查

| 類別 | 檢查什麼 | 適用 |
|---|---|---|
| **格式** | 中英文、數字之間的空格，全形標點，「」《》的用法，破折號（見寫作規範第二節） | 原有＋新 |
| **用詞** | 「基本收入」、專有名詞統一寫法、三種國際活動有沒有混用、台灣用語（見寫作規範第一節） | 原有＋新 |
| **錯字** | 同音或形近的錯字，例如在／再、的／得／地、做／作、已／以 | 原有＋新 |
| **語意** | 讀不懂、主詞不清楚、句子太長、前後矛盾 | 原有（只提明顯的）＋新 |
| **AI 腔** | 寫作規範第四節的那張表 | 只看新內容 |
| **事實** | 數字、日期、金額、人名、頭銜、引言，有沒有來源；**同一件事在網站其他頁面的寫法是否一致**（例如追蹤人數、實驗金額） | 只看新內容 |

**不要校的東西：**

- `<cite>` 裡的外部作品標題：照原文，見寫作規範第七節
- 引述某個人說的話：照原文逐字保留。懷疑是抄錯時，只提「請對照原始來源」，不要自己改
- 機關、學校的正式名稱：照官方寫法

### 4. 分成「直接改」和「要問」

負責人不需要為了「少一個空格」逐條點頭。**規則寫死、沒有判斷空間的直接改；
牽涉到「想怎麼說」或「事實對不對」的，才停下來問。**

| 直接改（改完列出來） | 要問（對方回覆了才改） |
|---|---|
| 格式：空格、全形標點、「」《》、破折號 | 語意：要改寫句子才通順、太空泛、AI 腔 |
| 專有名詞與台灣用語的統一寫法（寫作規範第一節的表） | 「無條件基本收入」「全民基本收入」是不是必要的用法 |
| **明顯的**錯字，例如「再申請期間內」→「在申請期間內」 | 不確定是不是錯字（可能是刻意的寫法） |
| | 原有內容超過格式、錯字的改動 |
| | 事實找不到來源，或跟其他頁面的寫法不一致 |

拿不準該放哪一邊，就放「要問」。

### 5. 回報結果

**位置用白話講**（「生活自由計畫頁，『誰可以報名』第二段」），不要只給檔名和行號。
直接改的列在前面，要問的編號列在後面。

格式示意（內容是虛構的，只示範長相）：

```
校稿完成。已直接修正 3 處：
- 格式 2 處：數字加空格、破折號改冒號（參與者近況，第一段）
- 錯字 1 處：「再申請期間」→「在申請期間」（誰可以報名，第二段）

有 2 件事需要你決定：

1. 參與者近況，第二句建議改寫
   原文：透過這筆收入，參與者得以重新找回生活的節奏與可能性
   建議：有了這筆錢，參與者開始重新安排每天的時間
   理由：原句太空泛
   → 要改嗎？

2. 「3 位參與者都已領到第 1 個月的款項」找不到來源
   → 請提供來源，或我把這句刪掉
```

**沒有要問的事，就說「已修正 N 處，沒有需要你決定的」**，不用等對方回覆，直接往下走。
什麼都不用改，就說「校稿完成，沒有問題」。
不要為了顯得有做事而硬找問題，更不要把原有內容改寫成你覺得比較好的說法。

對方回覆之後，**只改對方同意的**，改完列出改了哪幾條。直接改的部分，
對方說要改回去就改回去，不要爭。

如果是在 [推上去](推上去.md) 的途中校稿，接著跑那份流程的下一步（自動檢查）。
**不要校稿完就送出**：推上去流程在送出前還有「最後確認」，要讓對方在預覽網頁上
看過最後的樣子。PR 說明的「校稿」欄填上結果，例如
「直接修正 3 處；2 件事詢問，改寫 1 句、補來源 1 項」。

## 你要檢查什麼

| | 怎麼看 |
|---|---|
| **它直接改的，是不是只有格式和明顯錯字？** | 它應該列出直接改了什麼。如果連句子都被改寫了卻沒問你，請它改回來 |
| **你看得懂它的問題嗎？** | 每個問題都應該講清楚在哪一頁、哪一段、為什麼。只有檔名和行號，請它用白話再講一次 |
| **它有沒有改動原本的語氣？** | 原有內容應該只有格式和錯字被改。它想改寫原有的句子時，應該先問你，你可以拒絕 |
| **新內容的事實都有來源嗎？** | 找不到來源的，它應該問你。不要放著不管，補來源或刪掉 |

## 常見問題

**Q：已經有自動檢查了，為什麼還要校稿？**

自動檢查只抓得到規則明確的事：破折號、少空格、簡體字。
錯字、語意不通、AI 腔、數字寫錯，機器判斷不出來，要靠校稿。

**Q：為什麼有些地方它沒問我就改了？**

格式（空格、標點）和明顯的錯字，規則寫死、沒有判斷空間，問你只是多一道手續。
它會列出改了哪些，你不同意就說「第幾處改回去」。
要改寫句子、或牽涉到事實的，它一定會先問你。

**Q：我覺得它的建議不對。**

直接說「第 3 條不要」就好，不需要解釋。你比它更懂協會想怎麼說。
如果它的建議跟寫作規範有關，而你覺得規範本身該改，跟維護網站的人提出來。

**Q：校稿可以順便幫我把文章寫得更好嗎？**

那是另一件事，直接說「這段幫我改寫，讓它更 XX」就好。
校稿的原則是只指出問題，不主動改寫。
